按下面的步骤，可以在几分钟内跑起一个可编辑的文档站。

## 环境要求 {id="requirements"}

- Node.js 24（`website/.nvmrc`，进入该目录后可用 `nvm use` 切换）
- Git
- npm（随 Node.js 安装）

先确认版本：

```bash
node --version
npm --version
git --version
```

预期 `node --version` 以 `v24.` 开头，其余两个命令能输出版本号。如果没有 `nvm`，
也可以直接安装与 `website/.nvmrc` 一致的 Node.js 版本。

## 从模板创建仓库 {id="create"}

1. 打开模板仓库，点击右上角 **Use this template → Create a new repository**。
2. 选择仓库所有者和名称；若准备使用 GitHub Pages，仓库可以是公开仓库。
3. 创建完成后，复制新仓库的 Git 地址。

如果 GitHub 页面没有 **Use this template**，说明源仓库尚未启用 Template
repository。你仍可以 fork，或下载代码后推送到一个空仓库。

```bash
git clone https://github.com/your-org/your-docs.git
cd your-docs
```

## 在本地启动 {id="local"}

进入 `website/` 后安装依赖并启动开发服务器：

```bash
cd website
nvm use
npm install
npm run dev
```

终端出现 ready 提示后，打开 [`http://localhost:3000`](http://localhost:3000)。你
应该看到模板首页，并能从右上角进入“入门”“编写”“发布”三个大章节。

另开一个终端运行：

```bash
npm test -- --runInBand
```

看到全部测试通过，说明文档、配置和导航在修改前是一致的。后续每完成一个章节，都用
同一命令检查一次。

开发服务器适合日常写文档。它不会生成 Pagefind 搜索索引；需要验证搜索时，使用
[本地搜索](/zh-CN/publishing) 中的预览命令。

## 写第一篇文档 {id="first-page"}

顶部导航里已经有“入门”“编写”“发布”。这一步把一页加进你刚打开过的“入门”。

在仓库根目录创建 `docs/zh-CN/getting-started/hello.mdx`。`getting-started` 是“入门”的
目录名，文件放在这里，就是加进这一章。文件名 `hello` 会变成地址的后半段。

```mdx
---
title: 你好
teaser: 我的第一篇文档
section: getting-started
---

用 Markdown 写正文即可。
```

两行 `---` 之间的内容叫 frontmatter。站点用它显示页面，正文里不会出现这几行：

- `title`：页面大标题。打开后，页首应显示“你好”。
- `teaser`：标题下面的一句摘要，这里是“我的第一篇文档”。
- `section`：这一页属于哪个大章节。写成目录名 `getting-started`，也就是“入门”。

保存后打开
[`http://localhost:3000/zh-CN/getting-started/hello`](http://localhost:3000/zh-CN/getting-started/hello)。页首是“你好”，下面是“我的第一篇文档”。

恭喜你，已经添加了第一个文档。

左侧导航、组件和图片在 [编写](/zh-CN/writing) 里。站点名称、新增大章节和首页外观也在那
一章的后面。
